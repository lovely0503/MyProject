# GPT와 Claude 공통 작업 규칙 사용법

> GPT와 Claude가 같은 기준으로 일하게 하려면 공통 작업 규칙을 파일로 정하고, 두 AI가 그 파일을 읽도록 한다.

## 공통 규칙을 만드는 이유

같은 요청도 AI마다 해석이 달라 날짜나 파일명 형식이 달라질 수 있다. 사용할 형식과 예외 처리 방법을 구체적으로 적고 예시를 함께 제공하면 결과를 맞추기 쉽다.

## 날짜 규칙 예시

프로젝트 루트에 `작업규칙.md`를 만들고 다음 내용을 작성한다.

```markdown
# 공통 작업 규칙

## 날짜
- 시간대는 한국 시간(Asia/Seoul)을 사용한다.
- 날짜는 YYYY-MM-DD 형식으로 작성한다.
- 월과 일이 한 자리이면 앞에 0을 붙인다.
- 파일명은 "YYYY-MM-DD 제목.md" 형식을 사용한다.
- 새 문서에는 생성일을 기록한다.
- 기존 문서를 수정할 때 생성일은 바꾸지 않는다.
- 현재 날짜를 확인할 수 없다면 추측하지 말고 질문한다.

예시:
- 날짜: 2026-10-03
- 파일명: 2026-10-03 마크다운 실습.md
```

## 각 AI에 공통 규칙 연결하기

| 도구 | 안내 파일 | 넣을 내용 |
| --- | --- | --- |
| Codex | `AGENTS.md` | 작업 전에 루트의 `작업규칙.md`를 읽고 따르세요. |
| Claude Code | `CLAUDE.md` | 작업 전에 루트의 `작업규칙.md`를 읽고 따르세요. |

공통 규칙은 `작업규칙.md` 한 곳에서 관리하고 각 안내 파일은 그 파일을 참조하게 한다. 기존 안내 파일이 있다면 기존 내용을 유지하면서 참조 문장을 추가한다.

## 일반 ChatGPT·Claude 채팅에서 사용하기

일반 채팅에서는 로컬 파일이 자동으로 읽히지 않을 수 있다. 규칙 파일을 첨부하거나 내용을 붙여 넣고 다음처럼 요청한다.

> 첨부한 작업 규칙에 따라 문서를 만들어줘. 날짜와 파일명도 규칙에 맞춰줘.

## 현재 보관함에 적용하는 방법

`C:\kang`에는 기존 `CLAUDE.md`가 있으므로 다음 순서로 설정할 수 있다.

1. 루트에 공통 규칙을 담은 `작업규칙.md`를 만든다.
2. 루트에 `AGENTS.md`를 만들고 공통 규칙을 읽도록 안내한다.
3. 기존 `CLAUDE.md`에도 같은 안내를 추가한다.
4. 두 AI에 같은 작업을 요청해 날짜와 파일명 형식을 확인한다.

이 문서는 사용법을 정리한 노트다. 공통 규칙 파일 생성과 각 AI 안내 파일 연결은 별도로 적용해야 한다.

## 결과가 반드시 같아야 할 때

규칙 파일만으로 매번 완전히 같은 결과를 보장할 수는 없다. 날짜나 파일명처럼 정확한 일치가 필요한 값은 같은 스크립트로 생성하고, 두 AI가 그 스크립트를 사용하도록 하면 더 확실하다.
