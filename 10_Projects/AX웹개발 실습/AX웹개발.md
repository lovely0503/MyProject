# 웹사이트 개발 AX 경험 정리

> ChatGPT로 만들던 마크다운·HTML 작업이 크레딧 소진으로 끊기자, Claude로 옮겨 이어 가는 방법을 알아본 개인 기록.

| 항목 | 내용 |

## 4원인으로 보는 경험

### 목적 (왜 했나)

작업 중이던 문서와 웹 파일을 AI 도구가 바뀌어도 끊기지 않고 이어서 쓰고 싶었다.

### 질료 (무엇이 재료였나)

- ChatGPT에 폴더를 연결해 저장한 `.md` 파일과 `.html` 파일
- 수업에서 정리한 마크다운 가이드 노트
- 형식 연습용으로 만든 아리스토텔레스 프로필 노트

### 형상 (어떤 모습으로 남겼나)

- 프론트매터(제목, 날짜, 태그)로 시작
- 한 줄 요약 인용문, 정보 표, 번호 목록
- 마지막에 한 문장 정리

### 작용 (실제로 한 일)

1. ChatGPT에서 폴더를 연결해 마크다운과 HTML로 파일을 저장했다.
2. 크레딧이 떨어져 Claude에서 이어서 쓸 수 있는지 물어봤다.
3. 기존 파일을 채팅에 첨부하면 읽고 수정해 준다는 걸 확인했다.
4. 웹 채팅에서는 폴더 직접 연결이 안 되고, 데스크톱 도구가 필요하다는 걸 알았다.
5. 옵시디언 보관함은 `.md` 파일이 든 일반 폴더라서 별도 연동 없이 같은 폴더를 연결하면 된다는 걸 알았다.
6. 파일은 직접 저장하는 가벼운 방식으로 가기로 했다.

## 배운 점

- 마크다운과 HTML은 일반 텍스트라서 AI 도구를 바꿔도 파일이 그대로 호환된다.
- 폴더 연결은 웹 채팅이 아니라 데스크톱 앱에서 사용자가 직접 폴더를 지정하는 방식이다.
- 문서 모음에는 Claude Cowork, 웹 폴더에는 Claude Code가 맞는다고 안내받았다. (요금제에 따라 다를 수 있음)
- 연결이 번거로우면 채팅에 첨부하고, 결과를 내려받아 직접 저장하는 방법으로도 충분하다.
