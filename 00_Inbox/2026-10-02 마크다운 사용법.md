# 마크다운 사용법

마크다운은 간단한 기호로 제목, 목록, 링크 등을 표현하는 문서 작성 방식이다. 이 노트는 기본 문법과 옵시디언에서 자주 사용하는 기능을 정리한 참고 자료다.

## 1. 제목

`#` 뒤에 공백을 넣는다. `#` 개수가 많을수록 하위 제목이다.

```markdown
# 큰 제목
## 소제목
### 세부 제목
```

문서 제목은 `#`, 주요 구분은 `##`, 세부 내용은 `###`로 작성하면 읽기 쉽다.

## 2. 글자 강조

| 표현 | 입력 방법 | 결과 |
| --- | --- | --- |
| 굵게 | `**중요한 내용**` | **중요한 내용** |
| 기울임 | `*강조할 내용*` | *강조할 내용* |
| 취소선 | `~~삭제한 내용~~` | ~~삭제한 내용~~ |
| 형광펜 표시 — 옵시디언 | `==기억할 내용==` | ==기억할 내용== |
| 짧은 코드 | 백틱으로 감싸기: `` `코드` `` | `코드` |

## 3. 문단과 줄바꿈

- 문단 사이에는 빈 줄을 한 줄 넣는다.
- 줄바꿈만으로 보이는 결과는 편집기 설정에 따라 달라질 수 있다.
- 같은 문단에서 명시적으로 줄을 바꾸려면 줄 끝에 공백 두 개를 넣고 Enter를 누른다.

```markdown
첫 번째 문단입니다.

두 번째 문단입니다.
```

## 4. 목록과 체크리스트

### 순서 없는 목록

```markdown
- 첫 번째 항목
- 두 번째 항목
    - 하위 항목
```

### 순서 있는 목록

```markdown
1. 노트 만들기
2. 내용 작성하기
3. 다시 읽고 정리하기
```

### 할 일 목록

```markdown
- [ ] 아직 하지 않은 일
- [x] 완료한 일
```

- [ ] 마크다운으로 노트 작성하기
- [ ] 관련 노트 연결하기
- [ ] 작성한 내용 복습하기

## 5. 링크와 이미지

### 외부 웹사이트 링크

```markdown
[표시할 이름](https://example.com)
```

### 일반 마크다운 이미지

```markdown
![이미지 설명](이미지.png)
```

파일 경로는 현재 노트의 위치를 기준으로 맞춘다.

### 옵시디언 내부 링크

다른 노트를 연결할 때는 대괄호 두 쌍을 사용한다.

```markdown
[[노트 이름]]
[[노트 이름|화면에 표시할 이름]]
[[노트 이름#제목]]
```

- `[[노트 이름]]`: 해당 노트로 연결한다.
- `[[노트 이름|화면에 표시할 이름]]`: 링크에 보이는 이름을 바꾼다.
- `[[노트 이름#제목]]`: 해당 노트의 특정 제목으로 연결한다.

### 옵시디언 첨부 및 삽입

```markdown
![[이미지.png]]
![[다른 노트 이름]]
```

링크 앞에 `!`를 붙이면 이미지나 노트 내용을 현재 노트 안에 표시할 수 있다. 파일 이름은 보관함에 있는 실제 파일 이름과 맞춘다.

## 6. 인용문과 안내 상자

### 인용문

```markdown
> 기억하고 싶은 문장
```

> 배운 내용을 자신의 말로 정리하면 복습하기 쉽다.

### 콜아웃 — 옵시디언

```markdown
> [!tip] 작성 팁
> 한 노트에는 하나의 핵심 주제를 담는다.
```

> [!tip] 작성 팁
> 중요한 내용은 짧게 요약하고, 관련 주제는 내부 링크로 연결한다.

`[!note]`는 메모, `[!tip]`은 팁, `[!warning]`은 주의 사항에 사용할 수 있다.

## 7. 코드 블록

여러 줄의 코드나 원문을 그대로 보여주려면 앞뒤를 백틱 세 개로 감싼다. 여는 백틱 뒤에는 언어 이름을 붙일 수 있다.

````markdown
```python
print("안녕하세요")
```
````

## 8. 표와 구분선

### 표

```markdown
| 항목 | 설명 |
| --- | --- |
| 제목 | # 사용 |
| 강조 | ** 사용 |
```

표의 첫 줄은 제목 행이고, 두 번째 줄은 제목 행과 내용을 구분한다.

### 구분선

빈 줄 사이에 `---`를 단독으로 작성한다.

```markdown
위 내용

---

아래 내용
```

## 9. 태그와 속성 — 옵시디언

### 태그

본문에 `#공부`, `#마크다운`처럼 작성하면 주제를 분류할 수 있다. 태그에는 공백을 넣지 않는다.

- `# 제목`: 공백이 있으므로 제목 문법이다.
- `#태그`: 공백이 없으므로 태그다.

### 속성

노트 맨 위에 `---`로 감싼 영역을 두면 제목, 날짜, 태그 등의 속성을 기록할 수 있다. 이 노트에도 적용되어 있다.

```yaml
---
title: 마크다운 사용법
date: 2026-10-02
tags:
  - 마크다운
  - 옵시디언
---
```

## 10. 바로 쓰는 정리 양식

아래 내용을 복사해 새 노트에 사용한다. 날짜와 내용을 필요에 맞게 바꾼다.

```markdown
# 2026-10-02 학습 기록

## 오늘 배운 내용
- 핵심 내용 1
- 핵심 내용 2

## 기억할 점
> 한 문장으로 요약하기

## 할 일
- [ ] 직접 실습하기
- [ ] 복습하기

## 관련 노트
- [[관련 주제]]

#학습기록
```

## 자주 하는 실수

- 제목 기호 뒤에 공백을 빠뜨림 → `## 제목`처럼 작성한다.
- 체크박스의 공백을 빠뜨림 → `- [ ] 할 일`처럼 작성한다.
- 강조 기호를 한쪽에만 입력함 → `**내용**`처럼 양쪽에 입력한다.
- 코드 블록을 닫지 않음 → 마지막 줄에도 백틱 세 개를 넣는다.
- 모든 앱에서 같은 문법이 작동한다고 생각함 → 내부 링크, 콜아웃, 형광펜 표시 등은 앱에 따라 지원 여부가 다르다.

## 핵심 요약

**제목, 목록, 강조, 링크, 체크리스트**부터 익히고, 옵시디언에서는 **내부 링크와 태그**를 더해 노트를 연결한다.
