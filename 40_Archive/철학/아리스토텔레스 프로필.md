# 아리스토텔레스 프로필

> 고대 그리스의 철학자이자 논리학과 자연 연구를 체계화한 사상가. 윤리·정치·문학 등 여러 분야에서 오늘날까지 연구되고 있다.

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| 이름 | 아리스토텔레스 · Aristotle |
| 생몰년 | 기원전 384년 ~ 기원전 322년 |
| 출생지 | 고대 그리스 스타게이라 |
| 활동 | 철학자, 논리학자, 자연 연구자 |
| 스승 | 플라톤 |
| 대표 제자 | 알렉산드로스 대왕 |
| 교육 기관 | 아테네에 **리케이온** 설립 |
| 연구 분야 | 논리학, 윤리학, 정치학, 형이상학, 생물학, 문학 |

## 주요 생애

1. 약 17세에 플라톤의 **아카데메이아**에 들어가 약 20년간 공부했다.
2. 마케도니아에서 훗날 알렉산드로스 대왕이 되는 왕자를 가르쳤다.
3. 아테네에 **리케이온**을 세워 교육과 연구를 진행했다.
4. 기원전 322년, 칼키스에서 생을 마쳤다.

## 핵심 사상

### 관찰과 논리

실제 세계를 관찰하고 근거에 따라 설명하는 일을 중요하게 여겼다. 주어진 전제에서 결론을 이끌어 내는 추론을 연구했으며, **삼단논법**을 체계화했다.

### 행복과 덕

행복을 단순한 즐거움으로만 보지 않고, **좋은 성품을 기르고 실천하는 삶**과 연결했다.

### 중용

중용은 무조건 가운데를 선택하는 것이 아니라, **상황에 맞는 적절한 태도와 행동을 찾는 것**이다.

> 예: 용기는 비겁함과 무모함 사이의 덕이다.

## 대표 저서

| 저서 | 주요 주제 |
| --- | --- |
| 『니코마코스 윤리학』 | 행복, 덕, 좋은 삶 |
| 『정치학』 | 공동체, 정치 체제, 통치 |
| 『형이상학』 | 존재와 근본 원리 |
| 『시학』 | 비극과 문학, 이야기의 구성 |

## 오늘날의 의의

- **철학과 논리학:** 서양 철학과 논리학의 토대를 마련했다.
- **윤리와 정치:** 좋은 삶과 공동체에 관한 질문을 깊이 탐구했다.
- **자연 연구:** 동물을 관찰하고 분류하는 등 자연을 체계적으로 설명하려 했다.
- **문학:** 비극과 이야기의 구성에 대한 분석을 남겼다.

그의 주장 중에는 현대 학문에서 받아들여지지 않는 것도 있다. 하지만 세상을 관찰하고 논리적으로 설명하려는 연구 방식과 중요한 질문들은 오랫동안 영향을 끼쳤다.

## 한 문장 정리

**아리스토텔레스는 세상과 인간의 삶을 관찰과 논리로 이해하려 한 고대 그리스의 대표 철학자다.**
